# Cosmos 官网设计议会 — 四轮完整方案

> 角色：最强大脑（战略/概念）、UI/UX 主设、动效/交互设计师、视觉/艺术指导。  
> 参考：OpenAI（品牌分区与符号）、Anthropic（人性化与排版）、DeepMind（深蓝与科研感）、Perplexity（暗色与搜索焦点）、Scale AI（企业级信任感）。  
> 目标：发散、科幻、一眼厉害；每人针对页面设计元素出具完整方案。

---

## 第一轮：概念与世界观

### 最强大脑 — 战略与叙事层（~3000 字）

**1. 顶层叙事：从「产品介绍」到「进入宇宙」**

Cosmos 官网不应是「又一个 ToB 产品页」，而应让访客在 3 秒内完成一次认知跃迁：我进入的不是一家公司的首页，而是「积鲲宇宙」的入口。参考 OpenAI 用 Blossom 符号把人性与技术并置、Anthropic 用斜杠暗示代码与价值观的底层，我们需要一个**可被瞬间识别的宇宙隐喻**：数据是星尘，知识图谱是星座，决策是轨道，审计是轨迹。首屏不应堆砌功能点，而应呈现**一个正在运转的智能宇宙**——例如：中央是品牌名与一句宣言，背景是极简的「星图/网络/脉冲」动态暗示，无喧宾夺主的插图，让「宇宙」通过留白与微动效被感知。

**2. 信息架构与节奏**

整站应遵循「吸引 → 共鸣 → 理解 → 信任 → 行动」五拍。第一拍（Hero）：只做认知锚定与情绪代入。第二拍（为什么需要）：用**场景故事**而非功能列表——五个角色卡片可设计成「痛点舱室」：每张卡片像一艘飞船的舷窗，hover 时舷窗「亮起」、内部露出简短场景文案与一句「Cosmos 的回应」。第三拍（产品是什么/不是什么）：用**对比与边界**建立清晰心智，可配合一条时间线或双轨图（传统路径 vs Cosmos 路径）。第四拍（能力与架构）：此处必须**彻底告别 ASCII/表格式图表**，改为可交互的「宇宙分层」：五层架构 = 五层轨道或五层星环，每层可点击或 hover 展开该层模块，数据流用光带或粒子流表示。第五拍（行业、实施、信任、CTA）：保持同一视觉语言，用案例卡片、时间线、信任标识收束。

**3. 科幻感的尺度**

「科幻」在这里应理解为**精确、可解释、未来已来**，而非赛博朋克或游戏 UI。参考 DeepMind 的深蓝与渐变、Scale 的冷静企业感：主色建议**深空底（#0a0e17 或 #0f1729）+ 青/蓝主光（#22d3ee / #0ea5e9）+ 少量紫/品红作为强调**。避免大面积霓虹与闪烁；用**缓慢呼吸的光、细线网格、轻微扫描线**营造控制室/指挥舱的冷静感。字体上：标题用几何感强、有未来感但可读的无衬线（如 Orbitron、Exo、或 Plus Jakarta Sans 加宽字重）；正文保持高可读性（DM Sans 或 Inter），确保可访问性不因「炫」而受损。

**4. 差异化与「一眼厉害」**

「厉害」来自三点：**克制的力量感**（少即是多）、**一致的世界观**（每个区块都在讲同一套宇宙语言）、**一处令人难忘的交互**（例如五层架构的交互式星环，或 Hero 的实时「心跳」光晕）。建议在 Hero 下方设一条**动态指标带**：私有化部署 / 全链路可解释 / 99%+ 问数准确率，用极简图标 + 数字或短句，配合轻微数字滚动或光效，强化「这不是 PPT，这是正在运行的系统」的暗示。

### UI/UX 主设 — 组件与布局层（~3000 字）

**1. 导航与全局框架**

顶部导航在科幻语境下应像「控制栏」：背景为半透明深色 + 毛玻璃（backdrop-blur），边框用 1px 的浅色线或极细发光，高度控制在 56–64px，保证触控目标 ≥44px。Logo 可带极弱脉冲或静态光晕；主导航项在 hover 时出现下划线或底部光条（200–300ms ease-out），当前区块用细线或小三角指示。CTA 按钮与次级操作要有明显层级：主 CTA 用填充发光色，次要用描边或文字链。移动端采用汉堡菜单 + 全屏或侧滑抽屉，保持与桌面一致的视觉语言。

**2. Hero 区完整方案**

Hero 不塞满屏文字。主标题「Cosmos 积鲲宇宙」居中，字重 700–800，可配合字间距略加宽（tracking-tight 或 letter-spacing: 0.02em）。副标题一句即可：「让企业数据开口说话，让每一个决策都有据可依」。背景方案三选一或组合：  
- A) 深色渐变 + 多层径向渐变光晕（青/蓝），缓慢位移（10–20s 循环）；  
- B) 极细的网格线（0.5px，低透明度），模拟坐标平面；  
- C) 若干「光点」或「节点」分布，用 CSS 或轻量 canvas 做极慢的呼吸或连线动画。  
主次按钮并排，主按钮带轻微 box-shadow 发光，hover 时亮度与 scale(1.02) 微增。指标标签（私有化部署等）用 pill 形态，边框或背景为半透明，与背景融合。

**3. 痛点卡片（为什么需要 Cosmos）**

五张角色卡片 + 一张「根源」总结卡。布局：桌面端 3 列或 2+2+2，移动端单列。每张卡片：圆角 12–16px，背景为深色玻璃（rgba 白/深 + backdrop-blur），边框 1px 浅色或发光。标题为角色名，正文两段：痛点 + Cosmos 的回应。交互：默认略透明，hover 时边框亮起、背景略提亮、可选轻微上浮（translateY(-4px)）+ 阴影加深。根源卡可占满宽，视觉上作为「结论舱」，用不同背景色或左边框高亮区分。

**4. 「是什么 / 不是什么」区块**

采用左右或上下对比：左侧「是」— 三关键词（语义驱动、闭环决策、可信可控）配短句；右侧「不是」— 三条排除（不是 BI、不是中台替代、不是套壳问答），每条带图标或短横线。整体放在一块大卡片或分区内，与前后区块留足留白，保证扫读效率。

**5. 五层架构 — 彻底重设计（核心）**

废弃 ASCII 表格。方案：**垂直堆叠的五层「轨道」**。每层为一条横条或圆角矩形，内含：层名（入口层/智能层/…）、该层模块名（Genesis / Codex+Oracle+Emissary / …）。层与层之间用**竖线或渐变连接线**串联，表示数据/控制流。视觉：每层背景半透明，边框发光；hover 或点击时该层高亮（背景变亮、边框加强），可选展开该层说明。移动端可改为手风琴或横向滑动展示每层。色彩上可用同一色相不同明度区分层级，或统一青蓝系用透明度/厚度区分。

**6. 六大能力卡片**

六张能力卡，网格 2×3 或 3×2。每卡：图标（线性或轻量填充）+ 能力名 + 一句描述。风格与痛点卡统一：玻璃态、细边框、hover 上浮与光效。图标风格统一（如 Lucide 一套），色用主色或白色/浅青。

**7. 行业案例、实施、信任、CTA**

行业三卡并排，同上卡片语言。实施与信任可做两栏或时间线+列表。CTA 区：背景与 Hero 呼应（深色+光晕），标题+短句+双按钮，按钮尺寸与对比度满足 a11y。

**8. 可访问性与响应式**

所有交互元素保留 focus 环（2px 主色 outline），对比度 ≥4.5:1，支持 prefers-reduced-motion 关闭或减弱动画。断点：375 / 768 / 1024 / 1280，容器 max-width 约 1280px，左右留白随断点增加。

## 第二轮：动效与交互

### 动效/交互设计师 — 时间与反馈层（~3000 字）

**1. 整体动效原则**

动效为「呼吸」与「连接」服务，不为炫技。时长：微交互 150–300ms，区块进入 400–600ms，页面级过渡 200–300ms。缓动：进入用 ease-out，离开用 ease-in，连续动效用 cubic-bezier 或 steps 营造机械感时需谨慎，避免卡顿感。尊重 prefers-reduced-motion：检测到时关闭或大幅减弱位移/缩放，仅保留必要的透明度过渡。

**2. 首屏与 Hero**

首屏加载：标题与副标题可做极短 stagger（每项延迟 80–120ms）淡入+上移（opacity 0→1, translateY 8px→0）。背景光晕在页面加载后即开始缓慢位移或脉动（animation 10–20s infinite）。主 CTA 可带极弱脉冲（box-shadow 或 border 亮度周期变化，周期 2–3s），hover 时脉冲停止、改为实心高亮。

**3. 滚动触发的区块进入**

各主区块（为什么需要、产品能力、五层架构、六大能力、行业案例、实施与信任、CTA）进入视口时触发「进入」动画：区块内子元素（标题、卡片、列表）使用 Intersection Observer 或 CSS scroll-driven 动画，stagger 延迟 50–100ms，效果为 opacity 0→1 + translateY(24px)→0，duration 400–500ms。这样用户滚动时获得「逐层揭开」的节奏感，而非整页一次性出现。

**4. 五层架构的交互**

默认状态：五层自上而下静态展示，连接线为细线或渐变。Hover 某层时：该层背景亮度与边框增强，连接线可做「光带流动」的短动画（如 1s 的 gradient 或 stroke-dashoffset 动画）。若做「点击展开」：点击后该层向下展开一块说明区域，再次点击或点击其他层收起，展开/收起用 300ms height 或 max-height + opacity，避免 layout thrash。

**5. 卡片与按钮的微观反馈**

所有可 hover 卡片：transition transform 0.2s, box-shadow 0.2s；hover 时 translateY(-4px)，shadow 加深。可点击卡片或按钮：active 时 scale(0.98)，释放后回弹。焦点环在 focus 时 2px 主色 outline，offset 2px，确保键盘导航可见。

**6. 背景与氛围**

若使用网格或光点背景：动画极慢（transform 或 opacity 周期 ≥5s），幅度小（几个 px 或 0.1 透明度），避免分散注意力。若有「扫描线」：一条细线自上而下缓慢移动，透明度很低（如 3%），周期 8–10s，仅作氛围。

**7. 性能与兼容**

优先使用 transform 与 opacity 做动画，避免 width/height 和 layout。大量元素进入时使用 requestAnimationFrame 或 CSS animation，避免 JS 逐元素改 style。在低端设备或 reduced-motion 下可降级为仅淡入。

### 视觉/艺术指导 — 色彩、字体与氛围（~3000 字）

**1. 色彩系统**

主背景：深空 #0b0f19 或 #0f172a（slate-950），保证大面积沉稳。主光色：青蓝 #22d3ee（cyan-400）或 #0ea5e9（sky-500），用于主 CTA、关键标题、边框高亮、链接。次光色：蓝 #3b82f6 或紫 #8b5cf6，用于次要强调或渐变端点。中性：文字主色 #f1f5f9（slate-100），次色 #94a3b8（slate-400），禁用或辅助 #64748b（slate-500）。错误/警告若出现用语义色并配合图标。渐变：多用于背景光晕与按钮，如 linear-gradient(135deg, #0ea5e9 0%, #8b5cf6 100%) 或径向渐变从中心向外淡出。

**2. 字体**

标题：Plus Jakarta Sans 或 Orbitron/Exo，字重 700–800，行高 1.1–1.2。正文：DM Sans 或 Inter，字重 400–500，行高 1.6–1.75。数字与指标可用等宽或 tabular-nums。字号阶梯：12 / 14 / 16 / 18 / 20 / 24 / 32 / 40 / 48（px），移动端适当缩小标题。避免正文小于 14px，保证可读性。

**3. 玻璃与发光**

玻璃态：background: rgba(255,255,255,0.05) 或 rgba(15,23,42,0.6)，backdrop-filter: blur(12px)，border: 1px solid rgba(255,255,255,0.08)。发光：box-shadow: 0 0 20px rgba(14,165,233,0.15)，hover 可加强到 0.25。边框发光用 border-color + 可选 box-shadow 模拟，避免过亮导致刺眼。

**4. 图标与插图**

图标统一线性 1.5–2px stroke，圆角端点，风格一致（如 Lucide）。不在导航或关键操作使用 emoji。若有插图，建议抽象几何或节点/网络图，色系与主色一致，不抢文字。

**5. 五层架构的视觉规范**

每层为横向条块，内部左对齐层名、右或中为模块名。层与层间距 8–12px，连接线 1–2px，颜色为主色 50% 透明度。hover 层时该层与连接线提亮至 100%。若分层配色：入口层偏冷白，智能层主青，数据层偏蓝，执行层偏紫，应用层偏青绿，整体保持同一色相环相邻色。

**6. 留白与节奏**

区块上下 padding 80–120px（桌面），移动端 48–64px。区块内标题与内容间距 32–48px，卡片与卡片 24–32px。留白充足，避免拥挤，让「宇宙」感通过空间而非元素堆砌传达。

**7. 黑暗模式与一致性**

整站以深色为默认，无需单独切换。若未来做浅色主题，保持同一套语义色（主色、次色、背景、文字）映射，仅数值从深底浅字反转为浅底深字，对比度仍 ≥4.5:1。

## 第三轮：收敛与优先级

### 最强大脑 — 落地优先级与「一眼厉害」锚点

一致同意：五层架构必须从 ASCII 改为**可交互的垂直星环/轨道**，作为全站「记忆点」。Hero 保持极简，背景用深色+径向光晕+可选细网格。动效以 scroll-reveal 与 hover 为主，不做全页动画。色彩锁定深空底+青蓝主光+紫为辅。第一版实现：导航、Hero、痛点卡、是什么/不是什么、五层架构（交互式）、六能力卡、行业案例、实施与信任、CTA、页脚。后续迭代可加：指标带数字动效、背景光点连线、单页内锚点滚动指示。

### UI/UX 主设 — 组件清单与规范

所有卡片统一：圆角 12px、玻璃背景、1px 边框、hover 上浮 4px+阴影。按钮主 CTA 填充发光色，次 CTA 描边。五层架构每层最小触控高度 48px，连接线用 SVG 或 div+渐变。字体与色彩按艺术指导规范落地，间距按 8px 基准网格。

### 动效/交互 — 实现清单

Hero 标题 stagger 淡入；各 section 进入视口时子元素 stagger 上移+淡入；五层架构 hover 高亮+连接线光带（可选）；卡片/按钮 hover 与 active 态；prefers-reduced-motion 下仅 opacity 过渡。

### 视觉/艺术 — 设计令牌

--bg-deep: #0b0f19; --accent: #22d3ee; --accent-secondary: #8b5cf6; --text-primary: #f1f5f9; --text-muted: #94a3b8; --glass: rgba(255,255,255,0.05); --glass-border: rgba(255,255,255,0.08); --glow: rgba(14,165,233,0.2)。字体与间距见上。

## 第四轮：最终确认与交付标准

**一致决议：**

1. **世界观**：Cosmos 官网 = 进入「积鲲宇宙」的入口，冷静、精确、未来已来。  
2. **视觉**：深空底、青蓝主光、玻璃态卡片、细线连接、统一图标与字体。  
3. **核心重设计**：五层架构为垂直可交互轨道/星环，废弃 ASCII；其余图表若存在一律改为同语言的可视化组件。  
4. **交互**：滚动揭示、hover 反馈、五层 hover/展开、主 CTA 脉冲（可选）、尊重 reduced-motion。  
5. **可访问性**：对比度、焦点环、触控目标、语义结构、跳过链接均满足 WCAG 2.1 AA。  
6. **交付物**：单页 HTML（含 Tailwind 与必要内联脚本），无需构建；图表与动效用 CSS + 少量 JS（Intersection Observer）实现，保证在 Edge/Chrome/Safari 下一致。
