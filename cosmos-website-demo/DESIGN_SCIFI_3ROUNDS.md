# Cosmos 官网 · 科幻风格完整重设计 · 三轮方案

> 角色：顶尖视觉设计 × 动效设计 × 体验设计；目标：科幻感、电影级动效、一眼即「指挥舱/星图」的认知。

---

## 第一轮：视觉语言与世界观

### 1.1 世界观定义

**Cosmos 积鲲宇宙** 应被感知为「企业数据宇宙的指挥中枢」——不是普通 SaaS 首页，而是一进入就置身于一张**活的星图**：数据是星体，知识图谱是星座，决策是轨道，审计是轨迹。所有视觉与动效都服务于「正在运转的智能宇宙」这一隐喻。

- **空间**：深空为底，层次用「距离」表达——背景最远（几乎黑），中景是光晕与网格，前景是玻璃舱与文字。避免扁平色块堆叠。
- **光**：主光源为**青蓝冷光**（#22d3ee / #0ea5e9），辅光为**紫/品红**（#a78bfa / #c084fc），用于强调与数据流。光带、发光边框、粒子均为「能量」的视觉化。
- **材质**：玻璃（glass）、细线网格、轻微噪点/扫描线。避免纯色大块与过度渐变。

### 1.2 色彩系统（科幻调色板）

| 角色 | 色值 | 用途 |
|------|------|------|
| 深空底 | #06090f ~ #0b0f19 | 主背景、区块底 |
| 舱体灰 | #0f172a / #1e293b | 卡片、导航底 |
| 主光青 | #22d3ee | CTA、高亮、连接线、粒子 |
| 主光蓝 | #0ea5e9 | 渐变端点、链接 |
| 辅光紫 | #8b5cf6 / #a78bfa | 次要强调、第二层光晕 |
| 文字主 | #f1f5f9 | 标题、正文 |
| 文字次 | #94a3b8 | 说明、标签 |
| 警示/成功 | #34d399 / #fbbf24 | 仅用于状态点、pill 小点 |

渐变使用：线性 135deg 或径向，主光青 → 蓝 → 紫，透明度控制在 0.15–0.4，避免刺眼。

### 1.3 字体与排版

- **标题**：Plus Jakarta Sans 或 Orbitron，字重 700–800。Hero 主标题可适当加大字间距（0.02em–0.05em），副标题略紧。
- **正文**：DM Sans 或 Inter，字重 400–500，行高 1.6–1.75。
- **数据/代码感**：架构层名、模块名可用等宽或 tabular-nums 增强「系统」感。
- **层级**：用字号与字重区分，避免仅靠颜色；主标题可配合极细的发光 text-shadow（主光色、低透明度）。

### 1.4 布局与节奏

- **留白**：区块上下 80–120px（桌面），让「宇宙」通过空间呼吸；卡片与卡片 24–32px。
- **容器**：max-width 1280px，左右 gutter 随断点增加；内容不贴边。
- **分区线**：用 1px 细线 + 主光色 10–20% 透明度，或短渐变线（中间亮、两端淡），替代粗分割条。

### 第一轮产出小结

- 深空底 + 青蓝主光 + 紫辅光 + 玻璃/网格/细线材质。
- 字体与留白形成清晰层级；所有装饰服从「能量/星图」隐喻。
- 为第二轮动效提供色彩与语义基础。

## 第二轮：动效系统与节奏

### 2.1 动效原则

- **有因有果**：每个动效对应一次交互或一次进入视口，不无故自动循环（除背景粒子/光晕）。
- **时长**：微交互 150–300ms，区块进入 400–600ms，背景循环 15–25s。
- **缓动**：进入 ease-out，离开 ease-in；弹性用 cubic-bezier(0.34, 1.56, 0.64, 1) 仅用于重点元素（如 Logo、主 CTA）。
- **尊重 prefers-reduced-motion**：检测到时关闭或大幅减弱位移/缩放/粒子，保留必要透明度过渡。

### 2.2 页面加载与首屏

- **Hero**：背景网格 + 光晕先就位；标题、副标题、pill、按钮按 **stagger** 依次出现（每项延迟 80–120ms），opacity 0→1 + translateY(12–24px)→0，duration 450–550ms。
- **粒子**：首屏即启动，缓慢漂移 + 鼠标斥力；粒子间连线距离内绘制线段，形成「星图」。
- **光晕**：2–3 个径向渐变球缓慢位移（translate + scale 微变），周期 18–22s，营造景深。

### 2.3 滚动与视口进入

- **区块进入**：每个 section 进入视口时，其内标题、摘要、卡片/列表用 **Intersection Observer** 触发「进入」动画；子元素 stagger 50–100ms，效果为 opacity 0→1 + translateY(20–28px)→0，duration 500ms。
- **视差感**（可选）：背景光晕或网格的移动速度略慢于滚动，形成轻微视差；幅度控制在 5–10%，避免眩晕。

### 2.4 悬停与焦点

- **导航**：链接 hover 时文字亮起 + 底部 1px 光带从中心向两侧展开（width 0→100%）；主 CTA 保持发光，hover 时光泽扫过 + 轻微上浮。
- **Logo**：hover 时左侧光点放大、轨道旋转，文字字间距拉大 + 渐变字（白→青→白）；整体轻微 scale(1.02)。
- **卡片**：hover 时上浮 4px、边框与内光晕亮起；内光晕随鼠标位置（--mouse-x/y）移动；边框可选「光带扫过」。
- **架构层**：hover/focus 时该层背景与边框提亮，下方连接线亮起并播放「数据流」光点下落动画。
- **按钮**：主按钮 hover 光泽扫过；次按钮 hover 描边与背景微亮，可选渐变流动。
- **Section 标题**：hover 时 text-shadow 发光 + 底部渐变线展开。

### 2.5 背景与氛围

- **粒子**：Hero + CTA 两处 Canvas，粒子数 60–80 / 40；鼠标斥力半径 80–120px，斥力强度 0.05–0.08；连线距离 100–140px；颜色与主光/辅光一致。
- **光标光晕**：桌面端固定层跟随鼠标，径向渐变 + 模糊，低透明度（约 0.3），进入页面后 mousemove 时显示，mouseleave 文档时隐藏；触摸设备不显示。
- **扫描线**（可选）：全屏一层极低透明度（约 2–3%）水平线，自上而下缓慢移动，周期 8–12s，增强「终端」感。

### 第二轮产出小结

- 首屏 stagger 入场 + 粒子 + 光晕；滚动 reveal + 可选视差；全局 hover/focus 反馈统一（光带、上浮、光晕跟随）。
- 粒子与光标光晕仅非 reduced-motion 且桌面端；所有时长与缓动可落地为 CSS/JS 规范。

## 第三轮：组件级方案与落地规范

### 3.1 导航

- **结构**：sticky，高度 56–64px；背景 rgba(6,9,15,0.9) + backdrop-blur；底部 1px 线 border-white/10。
- **Logo**：左侧，光点 + 文字；hover 见 2.4；focus 环 2px 主色。
- **链项**：右排，间距 8px；每项 min 44px 触控区；hover 下划线光带；当前区可用细三角或短线指示（若做锚点高亮）。
- **主 CTA**：渐变主光 + 发光阴影；hover 光泽扫过 + translateY(-1px)。

### 3.2 Hero

- **背景**：网格（48×48px，线透明度约 3%）+ 2–3 个径向光晕（见 2.2）+ 粒子 Canvas（见 2.5）。
- **内容**：垂直居中；主标题一行「Cosmos 积鲲宇宙」，副标题一句，再一句产品定义；下方三枚 pill（私有化部署 / 全链路可解释 / 99%+ 问数准确率），每枚内含小色点；再下双按钮。
- **动效**：全部内容 stagger 淡入上移；pill hover 上浮 + 小点发光；按钮 hover 见 2.4。

### 3.3 痛点卡片（为什么需要）

- **布局**：桌面 3 列，移动 1 列；卡片间距 24px。
- **卡片**：玻璃底 + 1px 边框 + 圆角 12px；hover 上浮、边框与内光晕、可选边框光带；内光晕用 --mouse-x/y。
- **根源卡**：占满宽，左边框 4px 主色 + 背景主色 5% 透明度，与其余卡区分。
- **进入**：随 section reveal，卡片 stagger 延迟。

### 3.4 产品是什么 / 不是什么

- **容器**：单块大玻璃卡，圆角 16px，内边距 24–32px。
- **「不是什么」**：三条，每条加粗标签 + 说明；可左侧短竖线或小图标区分。
- **动效**：随 section 进入；无额外 hover（保持阅读焦点）。

### 3.5 五层架构

- **形态**：垂直堆叠，每层一条横条（圆角 10px），层与层之间 2px 高连接线（竖线）。
- **每层**：左为层名（主光色、字重 600），右为模块名（文字次色）；整体 min-height 56px，padding 16px 20px。
- **默认**：条块背景白 4%，边框白 8%；连接线为自上而下主光色渐变（上亮下淡）。
- **Hover/focus**：该层背景主光 8%、边框主光 35%、box-shadow 发光；连接线全亮；连接线内「数据流」光点下落动画（见 2.4）。
- **键盘**：每层 tabindex="0"，focus 同 hover 态。

### 3.6 六大能力 / 行业案例 / 实施与信任

- **卡片**：与痛点卡同一规范（玻璃、边框、hover 上浮与光晕、--mouse-x/y）。
- **标题**：section 标题统一为「section-title」：hover 发光 + 底部渐变线展开。
- **布局**：能力 3×2，案例 3 列，实施信任 2 列；间距统一。

### 3.7 CTA 区

- **背景**：与 Hero 呼应（网格 + 光晕）+ 粒子 Canvas（粒子数略少）。
- **内容**：标题 + 短句 + 双按钮 + 联系说明。
- **动效**：内容随 reveal；按钮同全局主/次按钮。

### 3.8 页脚

- **样式**：上边框 white/10；背景黑 20%；内品牌名 + slogan。
- **动效**：hover 页脚时品牌名轻微主光 text-shadow（可选）。

### 3.9 可访问性

- 跳过主内容链接；所有可聚焦元素 2px 主色 focus 环；对比度 ≥4.5:1；粒子与光标光晕在 reduced-motion 下关闭；触控目标 ≥44px。

### 第三轮产出小结

- 导航、Hero、卡片、架构、按钮、页脚均有明确结构与动效规范；色彩、字体、间距与第一二轮一致。
- 实现时：单页 HTML，Tailwind CDN + 内联 CSS/JS；粒子与 reveal 用原生 JS；CSS 变量统一主色与透明度，便于后续换肤。

## 三轮总结与落地清单

| 轮次 | 重点 | 产出 |
|------|------|------|
| 第一轮 | 视觉语言与世界观 | 深空青蓝紫配色、玻璃网格材质、字体层级、留白与分区线 |
| 第二轮 | 动效系统与节奏 | 首屏 stagger、滚动 reveal、hover/focus 统一反馈、粒子与光标光晕、时长与缓动 |
| 第三轮 | 组件级方案 | 导航/Hero/卡片/架构/能力/案例/实施/CTA/页脚的结构与动效落地规范 + a11y |

**落地顺序建议**：先按第一轮定色与字体；再按第三轮搭结构并套用第二轮动效（粒子、reveal、hover、Logo、按钮、架构流）；最后做光标光晕与可选扫描线，并做 reduced-motion 与触控测试。
