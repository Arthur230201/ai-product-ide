# 200 家企业设计体系调研计划

## 一、目标

- 产出 **200 份**企业/组织的**详细设计学习报告**。
- 每份报告基于该企业/组织**公开的设计系统或 UI 指南**的一手调研，包含：设计理念与原则、视觉与交互要点、组件与模式、可借鉴的共性结论。
- 最终将 200 份报告的共性归纳为本项目自用的设计理念与提示词，**不**依赖单一企业或特定领域词汇。

## 二、来源与名单

- **主要来源**： [Design Systems Directory](https://designsystems.directory/sites/)（240+ 条公开设计系统文档）、[awesome-design-systems](https://github.com/alexpate/awesome-design-systems) 等目录。
- **名单**：从上述来源去重、筛选后确定 **200 个设计系统**（一组织多系统时取其一或合并为一报告），按固定编号 001–200 建索引与报告文件。
- **优先纳入**：科技与软件、金融、零售、政府与公共部门、制造与工业、媒体与内容等多元行业，以覆盖 500 强级及全球知名产品 UI。

## 三、单份报告结构（详细）

每份报告需包含且不限于：

1. **组织与设计系统名称**：企业/组织名、设计系统或指南名称、官方文档/资源链接。
2. **设计理念与原则**：该体系明确提出的设计哲学、原则或价值观（引用或概括原文，并注明来源位置）。
3. **视觉与基础规范**：色彩、字体、间距/网格、圆角与阴影等基础规范要点。
4. **组件与模式**：主要 UI 组件类型、典型模式（如导航、列表、表单、数据展示）及约定。
5. **可访问性与包容性**：若有明确的无障碍、包容性设计要求，简要归纳。
6. **与本项目可借鉴的共性**：用 1–2 句话归纳可抽象为通用设计理念的要点（不绑定该企业或行业词）。

## 四、执行方式（分批）

- **批次**：每批 10 个设计系统，共 20 批（001–010, 011–020, …, 191–200）。
- **单批流程**：  
  1）按索引取本批 10 个条目；  
  2）逐个打开官方文档/资源页，阅读原则、基础规范、组件等；  
  3）按上述结构撰写详细报告并落盘；  
  4）本批完成后更新进度与可选“本批小结”。
- **产出位置**：  
  - `01-INDEX-200-ENTERPRISES.md`：200 条索引（编号、组织、设计系统名、官方链接）。  
  - `reports/001-{组织或系统简称}.md` … `reports/200-{组织或系统简称}.md`：每份对应一份详细设计学习报告。

## 五、进度与验收

- 每完成一批，在本文档或单独进度文件中更新「已完成批次」与「待完成批次」。
- 200 份全部完成后，再基于全部报告做**跨企业归纳**，形成本项目设计理念与提示词更新草案（见 `DESIGN_PHILOSOPHY_FROM_LEADING_PRODUCTS.md` 的迭代）。
