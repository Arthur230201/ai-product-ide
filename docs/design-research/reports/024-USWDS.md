# 024 U.S. Government - U.S. Web Design System (USWDS) 设计学习报告

## 1. 组织与设计系统名称

- **组织**：U.S. Government
- **设计系统名称**：U.S. Web Design System (USWDS)
- **官方链接**：https://designsystem.digital.gov/

## 2. 设计理念与原则

- **定位**：联邦政府设计系统，便于构建可访问、移动友好的政府网站；支持 21st Century IDEA，原则作为设计与实施决策的评估透镜。
- **核心原则**：  
  - **Start with Real User Needs** — 真实用户需求驱动产品决策；从设计之初纳入真实用户并持续用真实用户测试。  
  - **Earn Trust** — 通过可靠、一致、诚实赢得信任；理解并满足预期、通过扎实设计降低失败影响、妥善管理用户数据与时间。  
  - **Embrace Accessibility** — 可访问性融入每个决策、惠及所有人；超越 508 合规，关注不同交互方式下的可用性。  
  - **Promote Continuity** — 在服务全流程、时间、机构、平台与设备间提供一致体验。  
  - **Listen** — 收集反馈并响应用户需求。
- **采用方式**：通过成熟度模型渐进采用，从原则 → 指南 → 代码；提供 40+ 可访问、移动友好组件、token、工具与实现。

## 3. 视觉与基础规范

- 设计 token、工具类与实现帮助团队在不重复造轮子的前提下建设合规政府站点。

## 4. 组件与模式

- 40+ 组件覆盖表单、导航、数据展示等；文档与代码对齐。

## 5. 可访问性与包容性

- Embrace Accessibility 为核心原则；与 Section 508 及更广泛的可用性结合；成熟度模型将 a11y 纳入评估。

## 6. 与本项目可借鉴的共性

- **真实用户需求优先**：对应我们「页面目标与主内容区一致」、不以词汇特例驱动。  
- **Earn Trust + Continuity**：可靠、一致、跨端；对应我们通用原则与一致组件。  
- **可访问性内置**：不是事后检查而是设计前提；可纳入 DESIGN_PHILOSOPHY 与 HIGH_QUALITY_UI_DEFINITION。
