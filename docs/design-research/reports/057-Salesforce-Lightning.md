# 057 Salesforce - Lightning Design System 设计学习报告

## 1. 组织与设计系统名称

- **组织**：Salesforce
- **设计系统名称**：Lightning Design System (SLDS)
- **官方链接**：https://www.lightningdesignsystem.com/

## 2. 设计理念与原则

- **四条核心原则**：  
  - **Clarity** — 消除歧义，让人看得懂、能理解、有信心行动。  
  - **Efficiency** — 精简与优化工作流，智能预见需求，帮助人们更好、更聪明、更快速地工作。  
  - **Consistency** — 用同一方案解决同一问题，建立熟悉感、强化直觉。  
  - **Beauty** — 以深思熟虑与优雅的工艺，尊重人们的时间与注意力。
- **定位**：为 Salesforce 生态内应用与产品提供统一语言与一致观感；含设计指南、可复用组件、设计 token 及工具，支持高效构建企业应用体验。

## 3. 视觉与基础规范

- Design tokens 保证品牌与视觉一致；组件与模式与 token 配套，便于设计与开发对齐。

## 4. 组件与模式

- 组件库覆盖企业场景（表单、列表、数据、导航等）；模式与组件配套文档。

## 5. 可访问性与包容性

- 企业级产品通常将 a11y 纳入指南；具体标准需在 lightningdesignsystem.com 查阅。

## 6. 与本项目可借鉴的共性

- **Clarity / Efficiency / Consistency / Beauty**：可归纳为「清晰、高效、一致、尊重注意力」；对应我们 DESIGN_PHILOSOPHY 中的清晰与层级、一致性、克制用色。
- **同一问题同一方案**：对应我们「无特例」、推荐模式与组件复用。
