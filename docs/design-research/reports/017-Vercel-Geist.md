# 017 Vercel - Geist 设计学习报告

## 1. 组织与设计系统名称

- **组织**：Vercel
- **设计系统名称**：Geist
- **官方链接**：https://vercel.com/design/introduction/（Geist：vercel.com/geist）

## 2. 设计理念与原则

- **定位**：Vercel 的设计系统，用于构建一致的 Web 体验；同时作为品牌指南与设计框架。
- **资源**：Brand Guidelines（品牌资产）、Web Interface Guidelines（Web 界面指南）、Design System（核心系统）；Figma 库、代码仓库与组件文档。
- **团队**：设计团队涵盖设计、品牌与产品，负责维护与演进 Geist 及 Vercel 品牌。

## 3. 视觉与基础规范

- 通过 Figma 与代码库提供设计 token、组件与文档；面向 Web 应用，与 Vercel 产品线统一。

## 4. 组件与模式

- 组件文档与代码资源在 GitHub 与 design 站点；与 Next.js、Vercel 平台集成。

## 5. 可访问性与包容性

- 未在本次摘要中单独列出；Web Interface Guidelines 可能涉及，需在官网查阅。

## 6. 与本项目可借鉴的共性

- **品牌与产品一体**：从品牌指南到界面指南到设计系统一条线；对应我们「单一设计语言、一致层级」。
- **文档与代码双轨**：Figma + 代码库同步；对应我们推荐写法与真实组件一致。
