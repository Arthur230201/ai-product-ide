# 130 GOV.UK - GOV.UK Design System 设计学习报告

## 1. 组织与设计系统名称

- **组织**：GOV.UK
- **设计系统名称**：GOV.UK Design System
- **官方链接**：https://design-system.service.gov.uk/

## 2. 设计理念与原则

- **政府设计五原则**：Start with user needs（以用户需求为起点，用研究与分析而非假设）；Do less（少做、复用与共享，建可复用平台）；Design with data（用真实数据驱动决策，分析内置常开）；Do the hard work to make it simple（把复杂系统做成简单体验）；Iterate. Then iterate again（早发 MVP、与用户测试、根据反馈迭代）。
- **社区三原则**：Start with what exists（优先复用设计系统与社区已有组件与模式）；Contribute back and help others（贡献回馈、设计可复用组件）；Prioritise openness and honesty（尽早公开进展、坦诚研究结论与局限）。
- **定位**：通过经用户研究验证的可复用样式、组件与模式，帮助政府团队构建一致、可访问的服务。

## 3. 视觉与基础规范

- 可复用样式与组件；文档与代码在 design-system.service.gov.uk 与 GitHub 维护。

## 4. 组件与模式

- Patterns 与 Components 经用户研究验证；Get started 指导采用方式。

## 5. 可访问性与包容性

- 政府服务通常将可访问性作为强制要求；设计系统支持一致、可访问的组件与模式。

## 6. 与本项目可借鉴的共性

- **Start with user needs / Do less**：对应我们「页面目标与主内容区一致」、不做词汇特例；复用优先对应推荐写法与组件库。
- **Do the hard work to make it simple**：对应我们事前约束与高质量 UI 定义，把复杂生成收敛为简单、可预期结果。
- **Start with what exists、Contribute back**：对应我们「无特例」、新需求纳入系统而非单点破解。
