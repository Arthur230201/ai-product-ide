# 003 Workday - Canvas 设计学习报告

## 1. 组织与设计系统名称

- **组织**：Workday
- **设计系统名称**：Canvas Design System
- **官方链接**：https://design.workday.com/

## 2. 设计理念与原则

- **三条核心设计原则**：**Simple, Fast, Clever.** 指导决策并将迭代收敛到最佳方案。
- **定位**：Workday 产品开发的**单一事实来源**（single source of truth），通过维护规则、约束与最佳实践，实现快速、可持续的设计与开发，并在 Workday 产品间形成统一体验。
- **补充指南**：Content Style（声音、语调、UI 文案、语法）、Accessibility、Globalization，以支持包容与全球化体验。

## 3. 视觉与基础规范

- **Tokens**：设计系统的基础单元。
- **Assets**：图标与品牌资产。
- **Components**：按钮、容器、输入等 UI 元素及使用指南。
- **Responsive styling**：Canvas 提供响应式造型与适配说明（见 canvas.workday.com）。

## 4. 组件与模式

- 组件带使用指南，保证一致应用；Tokens 确保视觉与间距等决策可被代码与设计工具一致消费。
- 面向企业级产品（HR、财务等），强调清晰、高效与可扩展。

## 5. 可访问性与包容性

- 单独设有 **Accessibility Guidelines**，确保可访问设计以提升用户体验。
- **Globalization Guidelines** 支持全球与多语言场景，与包容性一致。

## 6. 与本项目可借鉴的共性

- **Simple, Fast, Clever**：可归纳为「简单优先、效率优先、聪明地复用」；对应我们强调的留白、层级与组件化，避免复杂与冗余。
- **单一事实来源**：设计系统即产品开发的唯一规范来源；我们通过 Constitution + Building Blocks + 推荐写法形成「生成前唯一约束」。
- **内容与可访问性并重**：Content Style 与 Accessibility 并列；对应我们将文案与可访问性纳入高质量 UI 定义。
