# 036 Starbucks - Starbucks Style Guide 设计学习报告

## 1. 组织与设计系统名称

- **组织**：Starbucks
- **设计系统名称**：Starbucks Style Guide
- **官方链接**：https://www.starbucks.com/static/reference/styleguide/

## 2. 设计理念与原则

- **理念**：在满足多元客户的同时保持品牌识别；追求「美丽、有表现力的时刻，以乐观、愉悦且一眼可辨的星巴克方式，带着沉静的自信」。
- **表达尺度**：从功能到表达的光谱——功能端（如移动点单）优先清晰，表达端（如社媒、个性化沟通）允许更多创意。
- **策略**：不做全面推翻，而是保持核心元素并刷新整体观感；强调叙事——将咖啡与艺术连接、把人与社区连接；品牌随用户演变而适应，同时保持可识别。

## 3. 视觉与基础规范

- **三大核心**：Siren 标志全触点一致；以绿色围裙为根的绿色系扩展；和谐字族约束，保持视觉统一。
- **六类要素**：Logo、颜色、声音、字体、插画、摄影。

## 4. 组件与模式

- 按渠道调整功能—表达比例；功能型优先清晰与可用性，表达型允许创意与个性化。

## 5. 可访问性与包容性

- 未在本次摘要中单独列出；多元客户与「meet customers on their terms」与包容性相关，具体 a11y 需在官网查阅。

## 6. 与本项目可借鉴的共性

- **功能—表达光谱**：按场景在「清晰可读」与「品牌表达」之间权衡；对应我们「内容与页面目标一致」且不牺牲可读性。
- **核心元素不变、整体可刷新**：对应我们设计原则中的一致性与克制用色，避免每次生成完全另起炉灶。
