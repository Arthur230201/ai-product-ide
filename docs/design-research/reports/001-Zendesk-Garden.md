# 001 Zendesk - Garden 设计学习报告

## 1. 组织与设计系统名称

- **组织**：Zendesk
- **设计系统名称**：Garden（当前主版本 Garden 9）
- **官方链接**：https://garden.zendesk.com/

## 2. 设计理念与原则

- **定位**：Garden 是 Zendesk 产品线的「单一事实来源」（source of truth），涵盖工具、标准与最佳实践，**有意模糊设计、内容策略与工程之间的界限**，以强化全产品套件的一致体验。
- **内容原则**（Content Principles，来自官方 Principles 文档）：
  - **Be clear**：帮助用户对操作感到安全、可预期。
  - **Be consistent**：降低学习与导航的摩擦。
  - **Be inclusive**：为最广泛受众创造可用体验。
- **内容写作**：面向所有人写作、使用主动语态、清晰优先于巧妙、避免行话、阅读水平约八年级。
- **模式（Patterns）**：将内容、设计与工程的最佳实践结合为「有主见的设计配方」，用于快速产出高质量界面。

## 3. 视觉与基础规范

- **间距**：Base-4 间距体系，间距与尺寸为 4px 的倍数。
- **字体**：San Francisco，默认 14px； typography 有标准化层级。
- **色彩**：调色板考虑对比度与可访问性要求（符合 WCAG 2.1）。
- **结构**：分为 Design（设计基础）、Components（组件与开发说明）、Patterns（UI 模式与配方）。

## 4. 组件与模式

- **Components**：提供开发指引，用于构建有效用户界面；与设计基础对齐。
- **Patterns**：组合多学科最佳实践的「配方」，加快高质量 UI 的产出，而非仅提供裸组件。
- **版本**：主站提供多版本入口（如 Garden 9 与历史版本），便于升级与兼容。

## 5. 可访问性与包容性

- 可访问性为**基础要求**，遵循 WCAG 2.1；强调可访问性惠及所有用户。
- 内容原则中明确「inclusive」与「避免仅依赖视觉的描述」，体现包容性写作。

## 6. 与本项目可借鉴的共性

- **设计·内容·工程一体化**：将内容策略与可访问性纳入设计系统，而不只做视觉与组件，有助于生成「可读、一致、包容」的 UI 文案与结构。
- **有主见的模式**：提供「配方」式模式而不仅是原子组件，可减少模型自由发挥导致的风格漂移；对应本项目的「推荐写法」与组件组合约定。
- **Base-4 与清晰层级**：稳定网格与字体层级可直接对应我们 8px 网格与 Constitution 中的字号层级。
