# 006 Wise - Wise Design 设计学习报告

## 1. 组织与设计系统名称

- **组织**：Wise（原 TransferWise）
- **设计系统名称**：Wise Design
- **官方链接**：https://wise.design/（https://www.wise.design/）

## 2. 设计理念与原则

- **范围**：覆盖**品牌与产品设计**，从「按钮到广告牌」保持一致体验（from button to billboard）。
- **结构**：Foundations（核心设计原则）→ Components（可复用 UI 元素）→ Patterns（常见设计解决方案）→ Resources（工具、下载与指南）。
- **多平台**：网站指南 + Figma（tokens、图标、插图、组件、屏幕模板）+ Neptune Web（Web 库）+ Android / iOS 实现。

## 3. 视觉与基础规范

- **Foundations 包含**：Colour, Grid, Padding, Radius, Size, Spacing；Typography, Icons, Illustration, Flags, Photography；Cards, Focus states, Transitions, Logo；Grammar and style, Tone of voice, Vocabulary, Markup；Mission, Promo assets, Tapestries。
- 设计元素同时服务品牌与产品，保证跨触点一致。

## 4. 组件与模式

- **Components**：可复用 UI 元素，与 Figma 及代码库对齐。
- **Patterns**：常见设计解决方案，减少重复决策。
- 支持通过 Slack #design-system 等渠道获取支持。

## 5. 可访问性与包容性

- 未在本次调研摘要中单独列出 a11y 章节；Foundations 中的 Focus states、Typography 等通常与可访问性相关，需在官网 Foundations 子页进一步查阅。

## 6. 与本项目可借鉴的共性

- **品牌与产品一体**：从最小 UI 到大型触点的统一语言；我们可强调「单一主色、一致层级、统一组件」以形成可识别的产品气质。
- **Foundations 先行**：颜色、网格、间距、圆角、字体等先定义再组件；对应我们 Constitution + Premium Brief 中的基础契约。
- **多端一致**：Web 与移动端共享设计系统；对应我们视口（桌面/移动）与组件库的同一套约束。
