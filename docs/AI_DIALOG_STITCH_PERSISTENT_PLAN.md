# AI 对话框：常驻 Stitch 风格 + 乔布斯结论落地方案与计划

> 目标：界面上给出**常驻的对话框**（与 Stitch 一致），其余部分按乔布斯 3 轮讨论结论收敛并执行开发。

---

## 一、方案摘要

1. **常驻对话面板**：右侧固定宽度（如 380px）的 Stitch 风格对话栏，**始终可见**，与画布/节点详情并列，不依赖「打开对话窗口」入口。
2. **CommandBar 简化**：底部条只保留「输入带」（附件 + 输入框 + 发送 + 必要进度/提示），**移除条内对话区**与「打开对话窗口」按钮；对话历史与澄清**全部在右侧常驻面板**完成。
3. **澄清内联**：追问与选项在常驻面板内展示，用户在同一面板内选择或输入，不弹窗、不跳转。
4. **画布联动**（可选本阶段）：生成/更新后对新节点短时高亮，建立「这句话 → 这块变化」的因果（可后续迭代）。

---

## 二、与乔布斯结论的对应

| 结论要点 | 落地方案 |
|----------|----------|
| 一个主入口、对话为画布服务 | 输入唯一在底部 CommandBar；对话展示唯一在右侧常驻面板；无两处入口。 |
| 澄清不打断 | 澄清在右侧面板内联展示，用户在同一流内回复。 |
| 空状态即邀请 | 面板空状态用一句行动建议 + 占位示例（如「在下方输入产品想法」），输入框 placeholder 为主引导。 |
| 信息有主次 | 底部条极简（仅输入+发送）；右侧面板承载全部对话与澄清，视觉权重明确。 |

---

## 三、布局与结构

### 3.1 整体布局

- **画布模式**（未打开节点详情）：`[ 画布 + 底部 CommandBar | 右侧常驻对话面板 ]`。左侧区域 `flex-1`，右侧面板固定宽度（如 `w-[380px]`），不遮盖画布。
- **节点详情模式**（已打开节点详情）：节点详情层不再全屏覆盖，改为占满**除右侧对话面板外**的区域，即 `[ 节点详情 | 右侧常驻对话面板 ]`；对话面板始终可见，与详情并列。

### 3.2 右侧常驻面板

- 位置：`fixed right-0 top-0 bottom-0` 或作为 flex 子项在文档流中 `flex-shrink-0 w-[380px]`。
- 内容：与现有 ConversationPanel 一致——对话列表（用户/AI 气泡）+ 澄清时底部输入/选项；**去掉**遮罩、关闭按钮（或改为折叠为窄条，可选）。
- 默认状态：**始终展示**（常驻），不依赖 `conversationPanelOpen` 才渲染；可选增加「折叠」状态，折叠后为右侧窄条（仅图标），点击展开。

### 3.3 CommandBar 简化

- **保留**：附件、输入框、发送、进度条/加载态、等待澄清时的禁用与横幅提示（提示文案可改为「请在右侧对话面板选择或输入」）。
- **移除**：条内对话区（上方 280px 对话列表）、「打开对话窗口」「在对话窗口中查看」「加载示例对话」等入口；可选保留一句轻量提示「对话在右侧」或仅靠占位 placeholder 引导。

## 四、开发计划（执行顺序）

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 布局：InfiniteCanvas 增加右侧常驻槽位 | 主区域与右侧 380px 并列；节点详情打开时仅占主区域，不覆盖右侧。 |
| 2 | ConversationPanel 改为常驻栏 | 去掉 `if (!conversationPanelOpen) return null` 与遮罩；在右侧槽位内始终渲染；关闭按钮改为折叠（可选）。 |
| 3 | NodeDetailPanel 不覆盖右侧 | 详情层使用 `right-[380px]` 或等效方式，为右侧对话面板留出空间。 |
| 4 | CommandBar 精简 | 移除条内对话区、移除「打开对话窗口」等按钮；保留输入区与等待澄清时的横幅/禁用。 |
| 5 | Store 与默认态 | 默认「对话面板可见」；如需折叠，用 `conversationPanelCollapsed` 控制，默认 false。 |
| 6 | 文案与无障碍 | 空状态与 placeholder 统一为行动式引导；`aria-label` / 焦点顺序与右侧面板一致。 |

---

## 五、不在此阶段做的

- 画布上新节点短时高亮（可后续迭代）。
- 对话持久化、多轮上下文、导出。
- 可拖拽停靠、画布内气泡等。
