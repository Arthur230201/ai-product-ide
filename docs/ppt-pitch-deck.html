乔布斯原则：用户只关心「看到什么、得到什么」。我们让设计、文档、实现同一源、零偏差。
典型痛点
UI 稿、PRD、接口文档与实现四处漂移；评审靠人工对照；交付物散落 Word/Confluence/代码库，难以单一事实来源。
我们提供
Fractal 画布上一节点四维：View / Spec / Impl / Test。描述即建图，建图即出 UI 与 PRD；导出 Word / HTML / 测试报告 / 系统设计说明，一键可达。

能力场景 三重输入引擎 产品
马斯克第一性：从「想法 / 文档 / 视觉」任一入口都能收敛到同一张图与同一套交付物，减少重复与歧义。
  • 想法 → 图：文本描述或上传文件，AI 生成产品结构图与节点，自动布局。
  • 文档 → 图：PRD 上传解析为画布节点，需求与页面一一对应。
  • 视觉 → 图：Figma/截图上传，识别界面与流程并落成节点与边。

能力场景 四维节点与 View 生成 产品
专家共识：每个节点即一个「页面/模块」的完整快照；View 由 PagePlan 规则或 LLM 合成，保证可读、可交付、可打印。
  • View：可运行 React/Tailwind 或单文件 HTML，沙箱预览；PagePlan 流水线：选模板 → 校验 → 渲染 → 写入节点。
  • Spec：从 View 反推或人工维护的结构化需求，支撑 PRD/SRS 导出。
  • Impl：接口与数据规格，支撑系统设计说明与 API 文档导出。
  • Test：用例与结果列，支撑测试报告导出。
