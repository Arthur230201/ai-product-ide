# 专家团队文档

本目录存放三方专家、内部团队与超级大脑的评审、讨论与裁决文档。

## 竞品可借鉴点流程（2025-02-05）

将热门竞品（v0、Theia Coder、Flexpilot、OpenCode、Jeda、Miro 等）的可借鉴点纳入项目的标准流程：

1. **详细拆解** → `COMPETITOR_LEARNINGS_BREAKDOWN_20260205.md`  
   按产品形态、技术架构、画布/节点、开源生态、UX 等维度条目化可借鉴点。

2. **超级大脑分析** → `COMPETITOR_LEARNINGS_SUPER_BRAIN_ANALYSIS_20260205.md`  
   综合马斯克（第一性原理）与乔布斯（体验口径）视角，产出采纳/不采纳/有条件采纳清单及两轮讨论议题包。

3. **两轮讨论** → `COMPETITOR_LEARNINGS_TWO_ROUND_DISCUSSION_20260205.md`  
   内部团队与三方团队基于同一议题包讨论两轮，产出共识清单与需裁决的分歧项。

4. **乔布斯与马斯克最终裁决** → `COMPETITOR_LEARNINGS_JOBS_MUSK_RULING_20260205.md`  
   对分歧项做最终裁决；裁决结论与共识清单合并为可执行清单。

执行顺序：拆解 → 超级大脑分析 → 两轮讨论（内部+三方）→ 裁决 → 按最终执行清单落地。
