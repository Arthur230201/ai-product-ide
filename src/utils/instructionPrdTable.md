# 指令流页面 - 业务需求规格表

| 功能ID | UI区域 | 元素名称 | 功能说明 | 展示规范 |
| :--- | :--- | :--- | :--- | :--- |
| ZLL001 | 顶部导航区 | 搜索框 | 用户输入关键词后，系统实时过滤指令列表，仅显示匹配的指令项。 | 🔍 搜索图标（左侧）+ ⚪ 白色背景输入框 + 🔵 聚焦时蓝色边框高亮 + 占位符："搜索指令..." |
| ZLL002 | 顶部导航区 | 排序下拉框 | 用户选择排序方式后，指令列表按选定规则重新排列（最新/最旧/按状态）。 | ⚪ 白色背景下拉框 + ⬇️ 下拉箭头图标（右侧）+ 🔵 聚焦时蓝色边框高亮 + 默认选项："最新" |
| ZLL003 | 列表区 | 指令卡片左侧指示条 | 用于标识指令的类别和优先级，创意落地类指令显示紫色，其他指令显示蓝色。 | 🟣 紫色（创意落地类别）或 🔵 蓝色（其他类别）+ 左侧固定宽度2px + 全高度显示 |
| ZLL004 | 列表区 | 指令标题 | 展示指令的核心内容描述，帮助用户快速识别指令主题。 | ⚫ 深灰色粗体文字 + 单行显示 + 超出部分省略 |
| ZLL005 | 列表区 | 状态标签 | 标识指令的当前流转状态，帮助用户了解指令处理进度。 | 🟦 进行中（蓝色背景+蓝色文字）或 🟢 已完成（绿色背景+绿色文字）或 ⚪ 待处理（灰色背景+灰色文字）+ 💊 胶囊样式圆角 |
| ZLL006 | 列表区 | 用户头像/图标 | 标识指令的负责人，当无头像时显示默认用户图标。 | 👤 用户图标（无头像时）或 📷 圆形头像（有头像时）+ 灰色背景 + 小尺寸（20px） |
| ZLL007 | 列表区 | 负责人姓名 | 展示指令负责人的姓名信息，便于用户识别责任人。 | ⚪ 灰色小号文字 + 位于头像右侧 |
| ZLL008 | 列表区 | 日期图标 | 配合日期文字，增强日期信息的视觉识别度。 | 📅 日历图标 + 灰色 + 小尺寸（12px） |
| ZLL009 | 列表区 | 指令日期 | 展示指令的创建或更新时间，帮助用户了解指令的时间信息。 | ⚪ 灰色小号文字 + 位于日期图标右侧 |
| ZLL010 | 列表区 | 来源标签 | 标识指令的来源渠道或分类信息（如"前端"、"后端"、"React"等），帮助用户快速筛选和归类。 | ⚪ 灰色背景标签 + 灰色文字 + 💊 胶囊样式圆角 + 可多个标签横向排列 |
| ZLL011 | 列表区 | 催办按钮 | 当指令需要紧急处理时，用户点击后触发催办操作，通知负责人加快处理进度。 | 🔵 蓝色文字按钮 + 悬停时蓝色背景高亮 + 仅在需要时显示（showActionButton=true） |
